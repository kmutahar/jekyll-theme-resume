{% comment %} ================================================================== START: HREFLANG TAGS FOR MULTILINGUAL SEO This logic generates the tags that tell search engines about the different language versions of this page. It only runs if a 't_id' (Translation ID) is set in the page's front matter. WHY THIS MATTERS: Search engines (Google, Bing, Yandex) require bidirectional hreflang links across all localized versions of equivalent content to prevent duplicate content penalties and to direct international visitors to the correct regional/language variant. HOW IT WORKS: - Pages representing the same document in different languages (e.g. English and Arabic CVs) share an identical `t_id` identifier in front matter. - site.pages is queried to locate all translation peers. - Absolute URLs are required by RFC 8288 and Google Search Console standards. - The 'x-default' fallback is explicitly mapped to the English edition for unmatched locales. ================================================================== {% endcomment %} {% if page.t_id %} {% comment %} 1. Find all pages on the site that share the *same* 't_id' as this current page. Store them in a new list called 'translations'. {% endcomment %} {% assign translations = site.pages | where: "t_id", page.t_id %} {% comment %} 2. Loop through every page found in the 'translations' list. 't' represents each individual page in the loop. {% endcomment %} {% for t in translations %} {% comment %} Print an 'alternate' tag for each page, using its 'lang' (e.g., "en", "ar") and its full 'url'. {% endcomment %} {% endfor %} {% comment %} 3. Find the site's default-language page from the 'translations' list to use as the "default" version. {% endcomment %} {% assign default_lang = site.default_lang | default: "en" %} {% assign default_page = translations | where: "lang", default_lang | first %} {% comment %} 4. If an English version was found, print the 'x-default' tag. This tells Google which page to show if the user's language doesn't match any of our versions. {% endcomment %} {% if default_page %} {% endif %} {% endif %} {% comment %} ================= End HREFLANG logic ================= {% endcomment %}
