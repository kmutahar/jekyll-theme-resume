{%- comment -%} Component: Social & Professional Links List - Purpose: Renders interactive social network and contact links defined in `site.social_links` in `_config.yml`. - Supported Platforms: Email, GitHub, LinkedIn, Telegram, Twitter/X, Medium, Dribbble, Facebook, Instagram, Website, WhatsApp, Dev.to, Flickr, Pinterest, YouTube. Architecture & Implementation Details: 1. Bundled Local SVGs: Vector icons are sourced locally from `_includes/vendors/svg-icons/`. Inlining SVGs eliminates external network dependencies and enables direct CSS fill/color inheritance. 2. Security & SEO Best Practices: - `target="_blank"`: Opens external profiles in a new tab. - `rel="noopener nofollow noreferrer"`: - `noopener`: Prevents the target page from accessing `window.opener`, neutralizing reverse tab-nabbing exploits. - `noreferrer`: Suppresses sending the HTTP Referer header to external servers. - `nofollow`: Informs search engine crawlers not to endorse outbound social links. 3. Schema.org Microdata Semantics: - Social profiles use `itemprop="sameAs"` to verify alternative digital identities of the person. - Direct communication channels and websites use `itemprop="url"`. 4. Hover State & Underline Suppression: - The anchor element carries class `icon-link`. - In `_sass/_all-pages.scss` and `_sass/_profile-page.scss`, `.icon-link`, `.icon-link:hover`, and `.icon-link:focus` explicitly enforce `text-decoration: none !important;` to prevent default browser link underlines from appearing underneath SVG icons. - `display: inline-flex; line-height: 0; align-items: center;` eliminates unwanted baseline font descent spacing. 5. WCAG 2.2 Accessibility: - Every icon anchor includes `aria-label=""`, `title=""`, and a visually-hidden ``. - The platform name comes from the page locale's `ui.social_labels.`, falling back to the English `label` in `_data/social_networks.yml`. Variables are `social_`-prefixed because includes share scope with the calling layout. 6. URL Safety: values pass through safe-url.html (email: bare address or mailto:; others: http/https only); a value with any other scheme renders no link at all. 7. Network List: platform key, icon filename, itemprop, and label all come from `_data/social_networks.yml` (one entry per platform) instead of one conditional block per platform here; see that file to add a new platform. {%- endcomment -%} {%- assign social_lang = page.lang | default: site.default_lang | default: 'en' -%} {%- assign social_locale = site.data.locales[social_lang] | default: site.data.locales[site.default_lang] -%} {% for network in site.data.social_networks %} {% if network.key == "email" %}{% assign social_schemes = "mailto" %}{% else %}{% assign social_schemes = "http,https" %}{% endif %} {% assign social_raw = site.social_links[network.key] %} {% include safe-url.html url=social_raw schemes=social_schemes %} {% assign value = safe_url %} {% if value %} {%- assign social_label = social_locale.ui.social_labels[network.key] | default: network.label -%}
