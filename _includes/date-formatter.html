{%- comment -%} Universal Date Formatter Formats a single date for any locale from _data/locales/.yml. Single canonical date formatting hook for every language, designed to cleanly host future calendar-system extensions (e.g. Feature 2.9 Dual Gregorian / Hijri Localization) without reintroducing language-isolated includes such as the legacy _includes/ar-date.html. Usage: {% include date-formatter.html date=role.startdate %} {% include date-formatter.html date=role.startdate style="MDY" %} {% include date-formatter.html date=role.startdate lang="ar" %} Parameters: - date: the date to format, or a present-tense marker string (e.g. "Present"). Required. - style: "MDY" for a full date, ordered by the locale's date_format_mdy; anything else (default "MY") for "Month Year". - lang: locale code to format in. Defaults to the active page/site language. {%- endcomment -%} {%- assign lang = include.lang | default: page.lang | default: site.default_lang | default: 'en' -%} {%- assign locale = site.data.locales[lang] | default: site.data.locales[site.default_lang] -%} {%- assign style = include.style | default: "MY" -%} {%- if include.date and include.date != "" -%} {%- comment -%} Case-insensitive match against locale.present_values (e.g. "Present", "حتى الآن") {%- endcomment -%} {%- assign date_downcase = include.date | downcase -%} {%- assign is_present = false -%} {%- for present_value in locale.present_values -%} {%- assign present_value_downcase = present_value | downcase -%} {%- if present_value_downcase == date_downcase -%} {%- assign is_present = true -%} {%- endif -%} {%- endfor -%} {%- if is_present -%} {{ locale.ui.present }} {%- else -%} {%- comment -%} Split the ISO string ourselves: Liquid's `date` filter reads a bare year (2018) as a Unix timestamp and cannot parse YYYY-MM. YAML Date objects stringify to YYYY-MM-DD. Anything that is not YYYY, YYYY-MM or YYYY-MM-DD is printed verbatim. {%- endcomment -%} {%- assign date_parts = include.date | append: "" | slice: 0, 10 | split: "-" -%} {%- assign year = date_parts[0] -%} {%- assign year_check = year | plus: 0 | append: "" -%} {%- assign month_num = date_parts[1] | plus: 0 -%} {%- assign day = date_parts[2] | plus: 0 -%} {%- assign month_name = nil -%} {%- if date_parts[1].size == 2 and month_num >= 1 and month_num <= 12 -%} {%- assign month_index = month_num | minus: 1 -%} {%- assign month_name = locale.months[month_index] -%} {%- endif -%} {%- if year.size != 4 or year_check != year or date_parts.size > 3 -%} {{ include.date }} {%- elsif date_parts.size == 1 -%} {{ year }} {%- elsif month_name == nil -%} {{ include.date }} {%- elsif style == "MDY" and date_parts.size == 3 and day > 0 -%} {%- assign mdy_pattern = locale.date_format_mdy | default: "{month} {day}, {year}" -%} {%- assign mdy_text = mdy_pattern | replace: "{month}", month_name | replace: "{day}", day | replace: "{year}", year -%} {{ mdy_text }} {%- else -%} {{ month_name }} {{ year }} {%- endif -%} {%- endif -%} {%- endif -%}
